# ARCSEC Checks

This directory is reserved for specific checks used to support ARCSEC standards.

Each check should state:

- What is being checked.
- When the check applies.
- What source, file, record, or system is being checked.
- What result is expected.
- How the result is recorded.

Checks should be tied to a defined ARCSEC standard, policy, SOP, skill, workflow, or system requirement.
