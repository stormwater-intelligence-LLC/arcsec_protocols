# ARCSEC Document Control

**System:** ARCSEC  
**Version:** 2.0 Draft  
**Status:** DRAFT  
**Owner:** Daniel Guzman  
**Date:** September 1, 2026

ARCSEC documents must show their current version and status.

## Status

ARCSEC uses the following document status:

**DRAFT → REVIEWED → APPROVED → ACTIVE → SUPERSEDED → RETIRED**

- **DRAFT** — still being developed or reviewed.
- **REVIEWED** — review completed; not yet approved for use.
- **APPROVED** — approved for use.
- **ACTIVE** — current version being used.
- **SUPERSEDED** — replaced by a newer approved version.
- **RETIRED** — no longer used.

## Changes

When an important ARCSEC document is changed:

- Record what changed.
- Record the date.
- Update the version when needed.
- Keep the previous version when it needs to remain part of the record.
- Review the new version before it becomes active.

## File Checks

SHA-256 may be used when a file needs to be checked against a recorded version.

A SHA-256 hash confirms whether the file matches the version that was recorded. It does not replace review of the file contents.
