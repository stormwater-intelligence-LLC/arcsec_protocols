# ARCSEC Standard 04 — Action Approval

**Version:** 2.0 Draft  
**Status:** DRAFT  
**Date:** September 1, 2026

## PURPOSE

This standard defines when approval is required before an action is performed.

## REQUIREMENTS

Before an important action is performed, the system must determine whether approval is required.

Approval may be required before actions such as:

- Sending or submitting information.
- Publishing content.
- Deleting or overwriting files.
- Changing production systems.
- Changing access or permissions.
- Connecting an external service.

If approval is required and cannot be confirmed, do not perform the action.

Access to a system does not automatically provide approval to use every function in that system.
