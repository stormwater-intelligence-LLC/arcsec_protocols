# ARCSEC Standard 03 — Sources and Information

**Version:** 2.0 Draft  
**Status:** DRAFT  
**Date:** September 1, 2026

## PURPOSE

This standard defines how sources are selected, reviewed, and used.

## SOURCE ORDER

When more than one source applies, the system must use the following order unless an applicable law, permit, contract, or approved project requirement establishes a different order:

1. Applicable law, regulation, permit, order, or other controlling requirement.
2. Official amendments, attachments, incorporated documents, instructions, and guidance that apply to that requirement.
3. Approved Stormwater Intelligence policies and operating standards.
4. Approved SOPs and controlled project procedures.
5. Approved skills and workflows used to perform the work.
6. Internal notes, training material, summaries, and other secondary references.

A lower source must not override a higher applicable source.

## REQUIREMENTS

The system must:

- Use the source that applies to the work.
- Review controlling and official requirements when the work depends on them.
- Keep enough information to identify the source used.
- State when the source does not provide the answer.
- Identify conflicts when sources disagree.
- Follow the higher applicable source when the conflict can be resolved by the source order.

The system must not:

- Create a source that does not exist.
- Claim a source was reviewed when it was not reviewed.
- Change the meaning of a source.
- Fill missing information with an assumption and report it as fact.
- Use a lower source to bypass a higher applicable requirement.

## SOURCE CONFLICT

If two applicable sources conflict and the source order does not resolve the conflict, the affected decision or action must stop.

The system must identify the conflicting sources and state what needs to be resolved before the work continues.
